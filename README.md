# Proyecto de Minería de Datos

## Almacenes y Minería de Datos 2027-1


Este repositorio contiene el desarrollo de un proyecto de Almacenes y Minería de Datos, enfocado en el análisis de información del sector salud mediante la metodología CRISP-DM. El objetivo es aplicar técnicas de integración, exploración, análisis y minería de datos para identificar patrones relevantes y generar información útil que facilite la comprensión de distintos fenómenos relacionados con la salud pública. El proyecto se desarrolla de manera incremental a lo largo del semestre, incorporando las etapas de comprensión del negocio, comprensión y preparación de los datos, modelado, evaluación y despliegue.
